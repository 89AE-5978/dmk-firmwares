# Firmwares OTA DMK

Repositório **público** usado pelas centrais DMK para baixar atualizações.
Contém somente `firmwares/manifest.json` e os arquivos `.bin` publicados. O código-fonte fica no repositório privado.

Endereço para colocar na central (Configurações → URL do servidor OTA):

```
https://raw.githubusercontent.com/89AE-5978/dmk-firmwares/main
```
